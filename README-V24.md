# خدماتي V24 — Controlled Pilot / Kill Switch

V24 تنقل المشروع إلى إطلاق تجريبي مضبوط بدل فتح كل العمليات مرة واحدة.

## الجديد
- وضع المنصة: `pilot / live / maintenance / paused`.
- مفتاح إيقاف سريع للدفع والسحب والطلبات الجديدة والتوزيع.
- سجل تدقيق لكل تغيير في إعدادات التشغيل.
- بوابة إطلاق V24 تعرض ما هو مسموح وما هو متوقف.
- توحيد `create_payment_order` ليستخدم idempotency key ويتحقق من بوابة الدفع.

## التشغيل
1. Backup لقاعدة البيانات.
2. نفّذ `V24-controlled-pilot.sql` بعد V23.
3. ابدأ بـ `pilot` مع الدفع والسحب متوقفين.
4. اختبر دورة الطلب كاملة بدون أموال حقيقية.
5. فعّل الدفع فقط بعد ربط Gateway واختباره.

V24 لا تجعل المنصة Live تلقائياً ولا تحتوي أسراراً أو مفاتيح دفع حقيقية.
