# خدماتي V25 — Canary Release & Observability

V25 تضيف طبقة اختبار إطلاق آمن قبل Live، مع سجل اختبارات وأحداث صحة المنصة.

## ما الذي تغير؟
- Canary runs محمية بصلاحية Admin.
- يمنع بدء Canary إذا كان الدفع أو السحب مفعلاً.
- يسجل نتائج checks وأحداث الصحة.
- لوحة جديدة في الإدارة: **🧬 اختبار Canary**.
- لا توجد أسرار أو مفاتيح دفع داخل المشروع.

## التشغيل
1. خذ Backup لقاعدة البيانات.
2. نفّذ `V25-canary-observability.sql` بعد V24.
3. افتح لوحة الإدارة → 🧬 اختبار Canary.
4. ابدأ الاختبار، نفّذ دورة الاختبار اليدوية، ثم اعتمد Pass/Fail.
5. لا تحول المنصة إلى Live قبل نجاح الاختبار والمطابقة المالية وربط بوابة الدفع الفعلية.

> V25 لا تدّعي أن الدفع الحقيقي أو Supabase أصبحا مفعّلين. إعداد `config.js` يظل مطلوبًا.
