# خدماتي V27 — Production Launch Gate

V27 هي قفزة التشغيل الفعلية: **بوابة إطلاق واحدة** تمنع اعتبار المنصة جاهزة قبل تحقق المتطلبات الأساسية.

## تشمل
- فحص إعدادات Supabase وعدم وجود مفاتيح وهمية.
- فحص وجود بيئة دفع Sandbox قبل تفعيل الدفع.
- فحص V20→V26 migrations بالترتيب.
- فحص توافق IDs مع `service_requests` و`providers`.
- فحص حالات السحب والدفع.
- فحص الأسرار: لا توجد مفاتيح حساسة داخل الواجهة.
- تقرير PASS/WARN/FAIL مع درجة جاهزية.
- Runbook مختصر للإطلاق الآمن.

**مهم:** لا تحتوي النسخة على بيانات Supabase أو مفاتيح دفع. لا تُعتبر Live حتى يتم إدخال بياناتك واختبار Sandbox فعليًا.
