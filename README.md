# خدماتي V1.3

نسخة V1.3 تجريبية تعمل مباشرة على GitHub Pages بدون خادم.

## الملفات
- `index.html` الواجهة.
- `style.css` التصميم المتجاوب للموبايل.
- `app.js` تسجيل الحساب والدخول والخروج باستخدام LocalStorage.

## ملاحظة مهمة
هذه النسخة مناسبة للتجربة والواجهة فقط. بيانات الحساب محفوظة محليًا داخل متصفح الجهاز، وليست نظام حسابات حقيقيًا على الإنترنت.

تسجيل الدخول بجوجل واسترجاع كلمة السر يحتاجان Backend وOAuth، وسيتم ربطهما في إصدار لاحق.
