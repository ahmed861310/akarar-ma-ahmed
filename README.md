# خدماتي V4.0 — المنصة العامة والنمو

هذه النسخة تنقل خدماتي خطوة أقرب للإطلاق العام: صفحات عامة، روابط قابلة للمشاركة لمقدمي الخدمات، تحسينات SEO، وكوبونات تجريبية قابلة للتوسعة.

## الجديد في V4.0
- 🌐 صفحة استقبال عامة تظهر قبل تسجيل الدخول.
- 🧑‍💼 استعراض مقدمي الخدمات بدون حساب.
- 🔗 رابط مباشر قابل للمشاركة لملف مقدم الخدمة باستخدام `#provider=...`.
- 📱 زر مشاركة يستخدم مشاركة الهاتف أو نسخ الرابط.
- 🔎 بيانات عنوان ووصف وOpen Graph للمشاركة على الشبكات الاجتماعية.
- 🎟️ نظام كوبونات تجريبي: `KHADAMATI10` خصم 10% بحد أقصى 100 جنيه، و`WELCOME50` خصم 50 جنيه للطلبات من 300 جنيه فأكثر.
- 💰 يظهر الخصم ضمن إجمالي الدفع في الوضع التجريبي.

## مهم قبل الإطلاق التجاري
الكوبونات في V4.0 محرك تجريبي داخل الواجهة. عند تشغيل الدفع الحقيقي يجب نقل حساب الخصم والتحقق من الكود إلى Backend/RPC آمن حتى لا يستطيع المستخدم تعديل السعر من المتصفح.
كذلك الدفع الحالي ليس بوابة دفع حقيقية؛ استخدم مزود دفع وWebhook وخادم آمن قبل استقبال أموال فعلية.

## التشغيل
- الوضع التجريبي: افتح `index.html` مباشرة واضغط «تجربة سريعة» لتجربة الحساب.
- الوضع الحقيقي: نفّذ `schema.sql` في Supabase، ثم ضع URL وanon key في `config.js`.

## المسار التالي المقترح
V4.1 يمكن أن يضيف نظام صفحات خدمة عامة، SEO ديناميكي، أكواد خصم محفوظة في قاعدة البيانات، تحليلات الإدارة، وربط دفع حقيقي عبر Backend.
