# خدماتي V1.9

واجهة عربية RTL لمنصة خدمات رقمية.

## الجديد في V1.9
- لوحة تحكم إدارية تجريبية.
- عرض إجمالي الطلبات والمستخدمين وحالات الطلبات.
- البحث في الطلبات.
- تغيير حالة الطلب: قيد المراجعة / جاري التنفيذ / تم التنفيذ / ملغي.
- تبويب للمستخدمين.
- مزامنة الطلبات مع قائمة مستخدمين محلية داخل المتصفح.

## مهم
هذه النسخة ما زالت تعمل بدون Backend؛ البيانات محفوظة في LocalStorage على نفس المتصفح والجهاز. زر دخول الإدارة تجريبي للعرض وليس نظام صلاحيات آمن. لا تستخدمه كحماية حقيقية قبل ربط Backend وقاعدة بيانات ومصادقة خادمية.
