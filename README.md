# خدماتي V2.1

نسخة جاهزة للانتقال من التخزين المحلي إلى قاعدة بيانات حقيقية باستخدام Supabase.

## التشغيل التجريبي
افتح `index.html` مباشرة. إذا تركت `config.js` فارغاً، سيعمل الموقع بالوضع التجريبي المحلي.

## التشغيل الحقيقي
1. أنشئ مشروع Supabase.
2. افتح SQL Editor والصق محتوى `schema.sql` وشغّله.
3. ضع `Project URL` و`anon public key` داخل `config.js`.
4. أنشئ حساباً من الموقع.
5. اجعل الحساب إدارياً من SQL Editor باستخدام الأمر الموجود في نهاية `schema.sql`.

## ملاحظات أمنية
- لا تضع `service_role` key في ملفات الموقع.
- كلمة السر لا يتم تخزينها في localStorage في الوضع الحقيقي؛ Supabase Auth يديرها.
- سياسات RLS تمنع المستخدم العادي من تعديل حالة الطلبات.


## إعداد الإدارة بأمان
بعد إنشاء حساب المدير، نفّذ أمر ترقية الدور الموجود في نهاية `schema.sql`. لا تسمح للمستخدمين العاديين بتعديل حقل `role`.

## النشر
يمكن رفع الملفات على GitHub Pages أو Netlify أو Vercel. اترك `config.js` بدون مفاتيح سرية، واستخدم فقط Supabase anon public key.
