# خدماتي ⚡ V1.6

نسخة تجريبية تعمل بالكامل داخل المتصفح.

## الجديد
- إنشاء حساب جديد بالاسم ورقم الهاتف وكلمة السر.
- تسجيل الدخول بالحساب المحفوظ محلياً.
- تجربة سريعة للدخول.
- تسجيل الخروج.
- واجهة عربية RTL ومتجاوبة مع الموبايل.

> ملاحظة: هذه النسخة لا تحتوي على خادم وقاعدة بيانات؛ بيانات الحساب محفوظة في localStorage على نفس الجهاز.
