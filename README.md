# خدماتي V1.3

نسخة محسّنة ومتجاوبة مع الموبايل والكمبيوتر.

## الملفات
- `index.html` واجهة تسجيل الدخول.
- `style.css` تنسيق متجاوب RTL.
- `app.js` التحقق البسيط والتفاعلات.
- `README.md` وصف النسخة.

## ملاحظات
هذه الواجهة Front-end فقط. تسجيل الدخول الحقيقي، Google OAuth، واستعادة كلمة السر تحتاج Backend أو خدمة مصادقة.

## GitHub Pages
ارفع الملفات الأربعة إلى جذر مستودع GitHub، وتأكد أن `index.html` موجود في الجذر، ثم انتظر إعادة نشر GitHub Pages.
