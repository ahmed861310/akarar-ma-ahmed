# خدماتي V1.5

نسخة أولى من لوحة خدمات عربية متجاوبة للموبايل والكمبيوتر.

## الموجود
- تسجيل دخول محلي.
- تجربة سريعة.
- لوحة رئيسية بعد تسجيل الدخول.
- خدمات: الطلبات، المدفوعات، متابعة الطلب، الشكاوى، الإشعارات، حسابي.
- حفظ جلسة المستخدم باستخدام localStorage.
- تسجيل خروج.
- تصميم RTL عربي ومتجاوب.

## التشغيل
افتح `index.html`.

## GitHub Pages
ارفع الملفات في جذر المستودع بجانب ملفات الموقع الحالية، ثم انتظر تحديث GitHub Pages.
