# خدماتي V2.3 — سوق مقدمي الخدمات

هذه النسخة تضيف **Marketplace** داخل خدماتي: المستخدم يستعرض مقدمي الخدمات، يبحث ويصنف النتائج، يرى السعر المبدئي ووسيلة التواصل، ثم يرسل طلباً لمقدم الخدمة. كما يستطيع المستخدم نشر خدمته كمقدم خدمة.

## التشغيل التجريبي
افتح `index.html` مباشرة. إذا كان `config.js` فارغاً يعمل الموقع محلياً، وتوجد 3 خدمات تجريبية جاهزة.

## التشغيل الحقيقي مع Supabase
1. أنشئ مشروع Supabase.
2. شغّل كامل ملف `schema.sql` في SQL Editor.
3. ضع Project URL وanon public key داخل `config.js`.
4. أنشئ حساباً من الموقع.
5. إذا أردت حساب إدارة، نفّذ أمر ترقية الدور الموجود في `schema.sql`.

## ما الجديد في V2.3
- صفحة **مقدمو الخدمات**.
- بحث وتصنيف لمقدمي الخدمات.
- بطاقة مقدم الخدمة: الاسم، نوع الخدمة، الوصف، السعر المبدئي، واتساب.
- زر **اطلب من مقدم الخدمة** ويرتبط الطلب بالمقدم في قاعدة البيانات.
- زر **أضف خدمتك** لنشر خدمة جديدة.
- جدول `providers` مع RLS.
- إضافة `provider_id` إلى الطلبات.
- الوضع التجريبي يعمل بدون Supabase.

## أمان
- لا تضع `service_role` key داخل الموقع.
- استخدم anon public key فقط.
- سياسات RLS تمنع المستخدم من إدارة خدمات الآخرين.

## النشر
يمكن رفع الملفات على GitHub Pages أو Netlify أو Vercel بعد ضبط `config.js`.


## V2.3 — نظام الثقة والعمولة
- صفحة بروفايل لكل مقدم خدمة.
- تقييمات العملاء من 1 إلى 5 نجوم وتعليقات.
- لا يظهر زر التقييم إلا بعد تنفيذ الطلب في الوضع الحقيقي.
- عداد الطلبات المكتملة والتقييمات ومتوسط التقييم.
- عمولة افتراضية لخدماتي 10% مع حفظ `platform_fee` داخل الطلب عند إنشائه.
- يمكن تغيير `commission_rate` لكل مقدم خدمة من قاعدة البيانات.
- في الوضع التجريبي تعمل التقييمات محلياً.

### مهم
V2.3 تتبع العمولة فقط؛ الدفع الإلكتروني الفعلي يحتاج ربط بوابة دفع مثل Paymob/PayTabs/Fawry لاحقاً، ولا يتم اعتبار الطلب مدفوعاً لمجرد تسجيله.
