# خدماتي V1.7
واجهة عربية RTL لمنصة خدمات رقمية، مستوحاة من نمط تطبيقات الخدمات الحكومية الحديثة، وليست نسخة من أي علامة تجارية.

## التشغيل
افتح `index.html` مباشرة في المتصفح.

## ملاحظات
- تسجيل الحساب والبيانات التجريبية محفوظة محلياً في المتصفح فقط.
- زر «تجربة سريعة» يدخل بحساب تجريبي.
- الخدمات الحالية واجهة تجريبية وتحتاج Backend/API لربطها بخدمات حقيقية.


## الجديد في V1.7
- شاشة تفاصيل لكل خدمة.
- إرسال طلب خدمة تجريبي وتخزينه محلياً.
- تحديث عداد الطلبات بعد الإرسال.
