# خدماتي V1.4

نسخة جديدة من المشروع تركز على تجربة الحساب.

### الجديد
- إنشاء حساب من الهاتف والاسم وكلمة السر.
- تسجيل دخول يعمل داخل المتصفح.
- حفظ الحساب والجلسة باستخدام `localStorage`.
- تسجيل خروج.
- واجهة استعادة كلمة السر مبدئية.
- تحقق من رقم الهاتف المصري.
- تصميم متجاوب للموبايل والكمبيوتر.

### تنبيه أمني مهم
V1.4 هي نسخة Front-end تجريبية. بيانات الحساب محفوظة في متصفح المستخدم عبر `localStorage` وليست نظام تسجيل دخول آمناً للإنتاج. لتسجيل دخول حقيقي وآمن نحتاج Backend وقاعدة بيانات وخدمة مصادقة.

### GitHub Pages
ضع `index.html` و`style.css` و`app.js` في جذر المستودع. GitHub Pages سيعيد النشر بعد الـ commit.
