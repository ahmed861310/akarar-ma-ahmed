# خدماتي V1
نسخة أولية تعمل مباشرة على المتصفح بدون خادم.

## التشغيل
افتح `index.html` في المتصفح، أو ارفع الملفات إلى GitHub Pages.

## الموجود في V1
- تسجيل الدخول
- إنشاء حساب
- حفظ اسم المستخدم محلياً
- الصفحة الرئيسية
- البحث في الخدمات
- بطاقات الخدمات
- الطلبات الأخيرة
- تنقل سفلي للموبايل

## ملاحظة
تسجيل الدخول هنا تجريبي فقط (LocalStorage). المرحلة التالية تضيف قاعدة بيانات وOTP وGoogle Login ولوحة تحكم.
