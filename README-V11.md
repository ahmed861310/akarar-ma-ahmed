# خدماتي V11 — Production Guardrails

## الجديد
- حماية idempotency لطلبات الدفع لمنع إنشاء عملية دفع مكررة عند إعادة المحاولة.
- فحص جاهزية المنصة من لوحة الإدارة.
- مركز تنبيهات للإدارة.
- التقاط أخطاء JavaScript وUnhandled Promise Rejections محليًا للمساعدة في التشخيص.

## قبل الإطلاق
1. طبّق `schema.sql` كاملًا على مشروع Supabase.
2. راجع RLS وEdge Functions ومفتاح `service_role`؛ لا تضعه في الواجهة.
3. اربط بوابة الدفع الحقيقية واختبر webhook بمبلغ تجريبي.
4. نفّذ رحلة اختبار كاملة من إنشاء الطلب حتى التحرير/الاسترداد.

**ملاحظة:** النسخة لا تعتبر Production مكتملة قبل نجاح اختبارات Supabase والدفع الفعلي في بيئة اختبار.
