# خدماتي V26 — Synthetic End-to-End Release Test

V26 تضيف مختبر E2E آمن داخل لوحة الإدارة. الاختبار لا ينشئ طلبات حقيقية ولا يخصم أموالًا ولا يتصل ببوابة دفع.

## ما الذي يفحصه؟
1. الوضع الآمن وإيقاف الدفع والسحب أثناء الاختبار.
2. مخطط Workflow.
3. طبقة التوزيع/المطابقة.
4. مخطط الدفع ودالة create_payment_order ذات 3 معاملات.
5. مسار التسوية.
6. دفتر العمولات.
7. Idempotency.
8. Observability.
9. Launch Gate.
10. حماية الإدارة.

## التشغيل
نفّذ `V26-e2e-release.sql` بعد نسخ احتياطي لقاعدة البيانات. ثم ادخل الإدارة ← 🧪 اختبار E2E ← تشغيل الاختبار الكامل.

> الاختبار Synthetic/Static integration test؛ نجاحه لا يعني أن بوابة الدفع أو Supabase أو الإطلاق التجاري جاهز تلقائيًا. يجب إجراء اختبار Sandbox منفصل قبل الأموال الحقيقية.
