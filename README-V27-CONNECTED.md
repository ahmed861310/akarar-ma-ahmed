# خدماتي V27 — Supabase Connected

تم تجهيز `config.js` ليتصل بمشروع Supabase الذي حدده صاحب المشروع باستخدام **Publishable key** المخصص للمتصفح.

## مهم
- لا يوجد أي `service_role` أو Secret Key داخل ملفات الواجهة.
- ما زال الدفع والسحب الحقيقيان بحاجة إلى إعدادات Edge Functions/بوابة الدفع قبل التشغيل المالي.
- بعد نشر الملفات، افتح لوحة الإدارة وشغّل **بوابة الإطلاق الفعلي V27**.

## الخطوة التالية
1. تطبيق ملفات SQL المطلوبة على مشروع Supabase.
2. تسجيل الدخول كمستخدم Admin.
3. تشغيل فحص V27.
4. بعد PASS، ننتقل إلى اختبار الدفع Sandbox.
